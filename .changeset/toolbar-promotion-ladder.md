On a wider screen the commands that lived in menus come out onto the toolbar, so free space is used instead of left empty. Six window widths each add some: at 1280 Share… is a button beside Export (the Share & export menu reads Export while Share… is on the bar); at 1440 Critical only (from Filter) and Health check (from Analysis) join it; at 1600 the Late-start overlay and Add: Start milestone; at 1912 the Colour by choice, Add: Finish milestone and Compare revisions; at 2160 Feasible window, Levelled placement and Earned value…; at 2560 Has conflict only, Resource histogram… and the Link kinds. Touch screens get the same, a stage later where the 44 px controls need the room, and Colour by arrives before the Late-start overlay. Resource view is now icon-only at every width, which is part of what makes the room. A command that has come out of a menu is no longer listed in it, and no menu is ever empty: Filter keeps Has constraint, Analysis keeps Baselines…, Export keeps its file formats and Print…, Link keeps Start → Finish, and Add keeps Task and Level of effort. Narrow the window and each command goes back into its menu; a promoted button says so in its tooltip ("Moves into the Filter menu in a narrower window").

If you are standing on a command in a menu when the window widens, focus moves to its new button and it is announced ("Critical only is now on the toolbar."). If you are in a menu or panel that a resize has to close, focus goes to the control that opened it and that is announced ("Menu closed because the toolbar changed."). If you are on a promoted button when the window narrows, focus lands on the menu that now holds it and the move is announced ("Moved into the Filter menu."). Closing the Health check or Compare revisions panel returns focus to its toolbar button when it has one. Assistive-technology names are unchanged ("Health check", "Share…", "Critical only") and a button in a set is named with the set ("Colour by: Total float"), and choosing a colour is announced ("Bars coloured by total float."). The banner that says editing is paused under the Late-start overlay names the control ("Turn off Late-start overlay") instead of the View menu it can now leave.
