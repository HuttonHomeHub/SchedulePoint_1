Put each plan tool on the surface of the thing it acts on. Plan summary and Edit plan details (the old header pencil, renamed so it is not one word from "Start editing") are icon buttons with tooltips on their own "Plan details" toolbar beside the plan's name. Legend, Resource view and Comments sit together in a new "Panels" group that closes the first deck row, and Plan closes the second. Float paths moves from the command deck to the selection bar and the Gantt row menu, where the activity it analyses is. Apply levelled dates… shows its label when the deck is wide. View ▾ is three columns with Structure, Markers and the Gantt's Columns folded until opened, so it fits a 1024 × 600 window without scrolling. Comments' tooltip now says "Show the plan's comments beside the diagram", and a Baseline overlay with no active baseline says how to set one.

Voice and assistive-technology commands that named these controls change: "Summary" is now "Plan summary", and "Edit plan" is now "Edit plan details".
