The Gantt's columns can now be sized. In the plan workspace's Gantt view, open `View ▾` and the Columns group shows a width field beside each shown column (Code, Duration, Start, Finish, Float left and Predecessors), a Table width field that matches the Grid width divider, and a Reset widths button. Type a width from 48 to 400 pixels and press Enter, or step it with the arrow keys; the Activity column gives up the room and the chart stays where it was. Widths are remembered on this computer and browser for every plan, and Reset widths puts every column and the table back to the standard layout. The printed programme keeps its standard page layout.
