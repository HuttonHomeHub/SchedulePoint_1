Plans can now have swimlanes. Open View, expand Structure and choose Set up swimlanes… to name them, then select activities and use Move to swimlane… to file them. Each swimlane is a labelled band on the diagram with its own lanes, and the list for screen readers is grouped by swimlane. Turning the Swimlanes checkbox off puts every bar back exactly where it was, and turning it on again brings the bands back. Adding, renaming, reordering, deleting and moving work between swimlanes can all be undone.
