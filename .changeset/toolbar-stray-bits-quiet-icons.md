The plan toolbar's last loose ends are tidied. Icons beside a visible label are now a step quieter than the label, so the pen is the only bright thing on the bar while you are not using a tool. Baseline overlay shows the word Baseline again on a wide window with a mouse (and stays an icon with a tooltip on a narrow window or on touch). The Start milestone and Finish milestone buttons drop the word Add from what they show, though screen readers still hear "Add: Start milestone". Recent edits now wears a history icon instead of an arrow. On a wide window, Settings moves to the end of the lower row behind a short divider, and Add and Undo each follow one, so the keyboard order follows what you see; on a narrow window they stay where they were, so no row gains a line.
