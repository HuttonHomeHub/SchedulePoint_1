The project screen's Calendars section has a **Remove unused calendars…** action. It lists the project's own calendars that no plan or activity uses, ticked for deletion except any that only a deleted plan or activity still uses, and deletes the ticked ones in one confirmation. Each deleted calendar can be restored on its own from Recently deleted. This clears the copies that earlier schedule imports left behind.
