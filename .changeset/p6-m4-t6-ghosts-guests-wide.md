Comparisons draw removed work in its code swimlane, and guests see swimlanes drawn from a code by name. When swimlanes are made from a code, a comparison against a baseline taken under the same code draws removed work in the band and lane it held; against a baseline taken under another code, or before codes existed, it counts what it cannot place, as it always has. A share link to such a plan shows the bands by name, with "No" and the code's name last, and never the codes themselves. The test catalogue gains a plan with 101 values in use, to prove a code with more values than a swimlane can draw is refused.
