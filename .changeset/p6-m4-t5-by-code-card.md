Swimlanes can be made from a code: in Set up swimlanes… or Swimlanes…, choose "One per value of" a code and pick which one. Each value in use gets a swimlane, in the order set in Codes…, with "No" and the code's name below for work that has none. A code with no values in use, or more than 100, is shaded with its reason. Switching between codes, the WBS and by hand keeps every layout, and the switch is one step you can undo. Delete… in Codes… is shaded for the code the swimlanes are made from.
