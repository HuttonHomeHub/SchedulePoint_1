On a narrow screen a Gantt view where you haven't chosen columns starts without the Code and Finish columns, so the timeline has room, and the Activity column also starts at its narrowest (drag it wider if you like). Switch them back on in View, Columns. Views where you already chose columns are unchanged. The divider between the table and the timeline starts afresh once on this update: if you had moved it, move it again. The same reset also clears a collapsed Gantt table once.
