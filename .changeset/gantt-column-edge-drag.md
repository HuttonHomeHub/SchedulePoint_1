A Gantt column can now be resized by dragging the right edge of its header. Press the edge of Code, Duration, Start, Finish, Float left or Predecessors and drag: the column follows the pointer, the Activity column gives up the difference and the chart stays where it was. The edge of the Activity column sets the table width, the same value as the Grid width divider. Double-click an edge to put that column back to its standard width. The width is saved once when you let go. Where there is a touch screen as the main pointer the edges are not shown; the width fields in View, Columns remain the way to set a width there and by keyboard.
