Cancel a request for control of a plan. When you have asked a colleague for control of a plan, a new
Cancel request button sits beside the waiting message, and after the countdown beside Take over now.
Pressing it takes the request back, so the plan is no longer handed to you when your colleague leaves,
and their "is asking to edit this plan" prompt goes away. If you reload the page after asking, your
request is remembered, so the message "you will start editing when they hand over or leave" is true
again. If a cancel cannot be sent, the message says so and the button stays.
