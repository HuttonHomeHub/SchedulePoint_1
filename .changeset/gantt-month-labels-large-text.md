The month names along the Gantt's date ruler no longer print over one another, or hang below the ruler, when the browser's text size is set to 200 %. The ruler now shows every second month, or only quarters, when the names would not fit. When the spacing would leave no month named at all, the first month in view is still labelled. At the normal text size nothing else changes, and the printed programme changes only where it used to show no month name.
