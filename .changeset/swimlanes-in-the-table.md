The Activities table now has a Swimlane column showing which swimlane each activity is in. Tick several activities and choose a swimlane under Move to swimlane to file them all in one step, which can be undone. The control explains why it is unavailable when you can't edit the plan. In a plan whose swimlanes follow the WBS the column is read-only and says so.
