A shared plan link now carries the plan's swimlanes. The shared plan view lists them (name only, in order), and each shared activity says which swimlane it is drawn in and its lane there, worked out by the same rule the planner's own diagram uses. The planner's raw swimlane assignments, the plan's swimlane source and any WBS settings are not shared. This applies to every link already issued; a plan whose swimlanes follow its WBS is still shared without them.
