Pressing a panel divider without dragging it now opens a small box where you can type the panel's size. It works on the Project Explorer, the activities table, and the Comments, Float paths, Health check and Revision comparison panels, and on the Gantt's table/chart line, with the same field as View, Columns, Table width. Type a size and press Enter; a size outside the range is limited and the box says so; Escape puts the box away and returns you to the line; "Reset to standard" puts the panel back. Dragging the line and moving it with the arrow keys work exactly as before, and no key opens the box. This is new for a mouse as well as a finger: a click on a divider opens the box. A size applied exactly as typed is announced, and a typed size lost to a press elsewhere is announced as not applied. In View, Columns, pressing Escape in a width field now throws away what you typed (before, it could apply it).
